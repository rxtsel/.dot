# My NixOS setup

NixOS setup based on a Solarized-style theme. This repository follows a dendritic pattern: hosts compose reusable system and user modules instead of baking user environments into global defaults.

If you download this repo, declare your local users with `my.users` in a host and compose each user's Home Manager environment from the modules under `modules/home/`.

## Structure

```text
.
├── assets/
│   └── wallpapers/        # Wallpaper collection
├── docs/                  # Notes and documentation
│   └── adr/               # Architecture decisions
└── modules/
    ├── home/              # Per-user Home Manager modules
    │   ├── cli/           # User CLI tools
    │   ├── core/          # Minimal Home Manager foundation
    │   ├── desktop/       # User desktop apps/config
    │   └── services/      # User services
    ├── hosts/             # Host-specific machine configs
    │   ├── blackout/      # Desktop host
    │   │   ├── default.nix    # NixOS configuration + user environments
    │   │   ├── disk.nix       # Declarative disk layout (disko)
    │   │   └── hardware.nix   # Auto-generated hardware config
    │   └── matebook-d15/  # Laptop host
    │       ├── default.nix
    │       ├── disk.nix
    │       └── hardware.nix
    └── nixos/             # Shared NixOS system modules
        ├── core/          # Minimal NixOS foundation
        ├── desktop/       # System desktop stack (compositor, DM, cursor)
        ├── services/      # System daemons (tailscale, gpg, fcitx5, localsend)
        └── system/        # Hardware and OS-wide config (audio, fonts, bluetooth)
```

To add a new host, create a folder under `modules/hosts/` with:
- `hardware.nix` — auto-generated by NixOS installer (`nixos-generate-config`)
- `disk.nix` — declarative disk layout for that machine (see [docs/disko.md](./docs/disko.md))
- `default.nix` — the NixOS config, composing modules and user environments
